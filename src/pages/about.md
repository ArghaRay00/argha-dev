I'm Argha, a software engineer based in Bangalore. I've spent the last 9 years building backend systems — mostly in Java and C# — at Motorola Solutions. The kind of work where you're debugging hex-encoded permission rulesets at 2am and writing Bash scripts that somehow become the team's deployment tool.

I also build things on the side. A streaming platform, an exam system rewrite, a personal AI agent — whatever I'm curious about that month.

## What I do at work

I'm on the Database Services team at Motorola, working on authorization services and PostgreSQL infrastructure for their push-to-talk platform. Before that, I spent a few years on a telecom provisioning portal — .NET, Angular, AWS Lambda, the usual enterprise mix.

The most fun thing I've built at work is a deployment tool in Bash that started as a script for myself and ended up being used by the team. It grew organically — someone needed rollback, someone else needed lock management — and now it's a real tool with health checks and auto-rollback. Not glamorous, but useful.

## What I build outside work

Mostly things I want to exist:

- A streaming platform for on-demand movie rentals — started as a proof of concept to learn HLS, ended up with two working versions (self-hosted and CDN-backed)
- A personal AI agent that runs on a VPS and talks to me on Telegram in Bengali
- An exam system that I originally wrote in college in .NET Framework 4.5, then rewrote in .NET 9 just to see how much the ecosystem has changed

I write Java, TypeScript, Python, C#, and Bash regularly. Other languages come and go depending on what I'm building.
