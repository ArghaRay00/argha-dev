I'm Argha Ray, a full-stack engineer with 9+ years of experience building enterprise systems, internal tools, and side projects. Currently at **Motorola Solutions** in Bangalore, working on authorization services, deployment automation, and telecom platforms.

I write Java, C#, TypeScript, Python, and Bash professionally. On weekends I build things in NestJS, React, Go, and whatever else catches my attention.

## Work at Motorola

**Authorization Service** — Built the role-based permission system covering 6 roles and 35+ resource types with hex-encoded rulesets. Wrote 666+ API integration tests across 22 modules. Fixed the Maven deploy pipeline after a broken Spring Boot dependency took down CI/CD.

**Universal JAR Deployer** — A 2,100+ line Bash tool used by 28+ developers sharing test servers. 14 commands including deploy, rollback, lock management, health checks with auto-rollback, and per-user timestamped backups.

**Other work** — Telecom management platform (OnePortal) with 28 API controllers and Okta auth. Device cloud services (MOTOTRBO) with 64 Lambda functions and MQTT. Carrier transition from Telna to Wirelesslogic. Ran a 2-day Agentic Engineering workshop for the team.
